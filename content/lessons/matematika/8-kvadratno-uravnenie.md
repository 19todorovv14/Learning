# Въведение

Квадратното уравнение е „работният кон“ на училищната алгебра: среща се в задачи с функции, геометрия, текстови задачи и почти сигурно — на матурата. Ако го решаваш бързо и без грешки, печелиш време за трудните задачи.

# Обяснение

## Вид

:::definition[Квадратно уравнение]
$$ax^2 + bx + c = 0, \quad a \neq 0$$
$a$ — коефициент пред $x^2$, $b$ — пред $x$, $c$ — свободен член.
:::

Внимавай със знаците: в $2x^2 - 3x - 5 = 0$ имаме $a = 2$, $b = -3$, $c = -5$.

## Непълни квадратни уравнения (без формула)

**1) $b = 0$:** $ax^2 + c = 0 \Rightarrow x^2 = -\dfrac{c}{a}$
- $x^2 = 9 \Rightarrow x = \pm 3$
- $x^2 = -4$ → **няма** реални корени

**2) $c = 0$:** $ax^2 + bx = 0 \Rightarrow x(ax + b) = 0 \Rightarrow x_1 = 0,\ x_2 = -\dfrac{b}{a}$
- $3x^2 - 12x = 0 \Rightarrow 3x(x - 4) = 0 \Rightarrow x_1 = 0,\ x_2 = 4$

:::warning[Не дели на x!]
От $x^2 = 5x$ не пиши „$x = 5$“ — губиш корена $x = 0$. Правилно: $x^2 - 5x = 0 \Rightarrow x(x - 5) = 0$.
:::

## Пълно уравнение — дискриминанта

:::formula[Дискриминанта]
$$D = b^2 - 4ac$$
:::

| $D$ | Корени |
|---|---|
| $D > 0$ | два различни реални корена |
| $D = 0$ | един (двоен) корен $x = -\dfrac{b}{2a}$ |
| $D < 0$ | няма реални корени |

:::formula[Формула за корените]
$$x_{1,2} = \frac{-b \pm \sqrt{D}}{2a}$$
:::

## Формули на Виет

Ако $x_1$ и $x_2$ са корени на $ax^2 + bx + c = 0$:

:::formula[Виет]
$$x_1 + x_2 = -\frac{b}{a}, \qquad x_1 \cdot x_2 = \frac{c}{a}$$
:::

При $a = 1$ (уравнение $x^2 + px + q = 0$): $x_1 + x_2 = -p$, $x_1 x_2 = q$ — често корените се „познават“ наум.

*$x^2 - 7x + 12 = 0$: сбор 7, произведение 12 → $x_1 = 3$, $x_2 = 4$.*

## Разлагане на квадратния тричлен

$$ax^2 + bx + c = a(x - x_1)(x - x_2)$$

# Примери

**Пример 1.** $x^2 - 5x + 6 = 0$: $D = 25 - 24 = 1$; $x_{1,2} = \dfrac{5 \pm 1}{2}$ → $x_1 = 3$, $x_2 = 2$.

**Пример 2.** $2x^2 + 3x - 2 = 0$: $D = 9 + 16 = 25$; $x_{1,2} = \dfrac{-3 \pm 5}{4}$ → $x_1 = \dfrac{1}{2}$, $x_2 = -2$.

**Пример 3.** $x^2 - 6x + 9 = 0$: $D = 36 - 36 = 0$ → $x = 3$ (всъщност $(x - 3)^2 = 0$).

**Пример 4.** $x^2 + x + 5 = 0$: $D = 1 - 20 = -19 < 0$ → няма реални корени.

**Пример 5 (Виет).** Без да решаваш $x^2 - 3x - 10 = 0$, намери $x_1^2 + x_2^2$.
$x_1 + x_2 = 3$, $x_1 x_2 = -10$. $x_1^2 + x_2^2 = (x_1 + x_2)^2 - 2x_1x_2 = 9 + 20 = 29$.

# Обобщение

- $ax^2 + bx + c = 0$, $a \ne 0$.
- Непълни: $b = 0$ → $x^2 = -c/a$; $c = 0$ → изнасяне на $x$.
- $D = b^2 - 4ac$; $x_{1,2} = \dfrac{-b \pm \sqrt D}{2a}$.
- $D > 0$ — 2 корена, $D = 0$ — 1, $D < 0$ — няма.
- Виет: $x_1 + x_2 = -b/a$, $x_1x_2 = c/a$.

# Записки

## Квадратно уравнение $ax^2 + bx + c = 0$ ($a \ne 0$)

**Непълни:**
- $ax^2 + c = 0$ → $x^2 = -\frac{c}{a}$ (≥ 0 → $\pm\sqrt{}$; < 0 → няма);
- $ax^2 + bx = 0$ → $x(ax + b) = 0$ → $0$ и $-\frac{b}{a}$.

**Пълно:**
$D = b^2 - 4ac$
- $D > 0$: $x_{1,2} = \frac{-b \pm \sqrt{D}}{2a}$
- $D = 0$: $x = -\frac{b}{2a}$
- $D < 0$: няма реални корени

**Виет:** $x_1 + x_2 = -\frac{b}{a}$; $x_1 x_2 = \frac{c}{a}$
**Разлагане:** $a(x - x_1)(x - x_2)$
**Полезно:** $x_1^2 + x_2^2 = (x_1 + x_2)^2 - 2x_1x_2$

# Важно за запомняне

- Минусът пред $b$ във формулата.
- $D$ решава колко са корените.
- Провери корените с Виет — 10 секунди.

# Чести грешки

- $-b$, когато $b$ е отрицателно: при $b = -5$ → $-b = 5$.
- $b^2$ при отрицателно $b$: $(-3)^2 = 9$, а не $-9$.
- Делене на $x$ — губи се коренът $0$.
- Да делиш само $\sqrt{D}$ на $2a$, а не целия числител.

# Определения

- **Квадратно уравнение** — уравнение от вида $ax^2 + bx + c = 0$, $a \neq 0$.
- **Дискриминанта** — числото $D = b^2 - 4ac$, което определя броя на реалните корени.
- **Непълно квадратно уравнение** — квадратно уравнение, в което $b = 0$ или $c = 0$.

# Въпроси от учителя

## Колко корена има уравнение с $D = 0$?

Един двоен корен $x = -\dfrac{b}{2a}$ — лявата страна е точен квадрат.

## Как с формулите на Виет проверяваш решението си?

Събирам и умножавам получените корени и сравнявам с $-b/a$ и $c/a$.

# Упражнения

## Задача 1 (лесна)

Реши: $x^2 - 16 = 0$.

### Решение

$x^2 = 16 \Rightarrow x = \pm 4$.

## Задача 2 (средна)

Реши: $3x^2 - 5x - 2 = 0$.

### Подсказка

$a = 3$, $b = -5$, $c = -2$.

### Решение

$D = 25 + 24 = 49$; $x_{1,2} = \dfrac{5 \pm 7}{6}$ → $x_1 = 2$, $x_2 = -\dfrac{1}{3}$.

## Задача 3 (трудна)

За кои стойности на $m$ уравнението $x^2 - 4x + m = 0$ има два различни реални корена?

### Решение

$D = 16 - 4m > 0 \Rightarrow m < 4$.

# Тест

## Колко е дискриминантата на $x^2 - 4x + 3 = 0$?

Число: 4

> $D = 16 - 12 = 4$.

## Колко реални корена има $x^2 + 2x + 5 = 0$?

- [x] Нито един
- [ ] Един
- [ ] Два

> $D = 4 - 20 = -16 < 0$.

## Кои са корените на $x^2 - 3x = 0$?

- [x] $0$ и $3$
- [ ] Само $3$
- [ ] $-3$ и $3$

> $x(x - 3) = 0$.

## За уравнението $x^2 - 7x + 10 = 0$ сборът на корените е:

Число: 7

> Виет: $x_1 + x_2 = -b/a = 7$ (корените са 2 и 5).

## Кои са корените на $2x^2 - x - 1 = 0$?

- [x] $1$ и $-\frac{1}{2}$
- [ ] $-1$ и $\frac{1}{2}$
- [ ] $2$ и $-1$

> $D = 1 + 8 = 9$; $x = \frac{1 \pm 3}{4}$.

## Ако $x_1$ и $x_2$ са корени на $x^2 - 5x + 6 = 0$, колко е $x_1^2 + x_2^2$?

Число: 13

> $(x_1 + x_2)^2 - 2x_1x_2 = 25 - 12 = 13$.

Трудност: 3
