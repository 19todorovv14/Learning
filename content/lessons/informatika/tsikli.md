# Въведение

Да отпечаташ числата от 1 до 1000 с 1000 реда код е безсмислено. **Цикълът** казва на компютъра: „повтори това действие толкова пъти“ или „повтаряй, докато…“.

# Обяснение

## Цикъл for

Използва се, когато **знаеш колко пъти** да повториш.

```python
for i in range(5):
    print(i)
```

Отпечатва `0 1 2 3 4` (всяко на нов ред).

**range:**

| Запис | Числа |
|---|---|
| `range(5)` | 0, 1, 2, 3, 4 |
| `range(1, 6)` | 1, 2, 3, 4, 5 |
| `range(0, 10, 2)` | 0, 2, 4, 6, 8 |
| `range(10, 0, -1)` | 10, 9, …, 1 |

:::warning[Краят не се включва]
`range(1, 6)` спира **преди** 6. Ако искаш числата от 1 до n, пиши `range(1, n + 1)`.
:::

## Цикъл while

Използва се, когато повтаряш, **докато** е вярно условие.

```python
n = 1
while n <= 100:
    n = n * 2
print(n)   # 128
```

:::warning[Безкраен цикъл]
Ако условието никога не стане невярно, цикълът не спира. Винаги проверявай, че **нещо в тялото на цикъла променя условието**.
:::

## Типични задачи

**Сума:**
```python
total = 0
for i in range(1, 101):
    total += i
print(total)   # 5050
```

**Брой (брояч):**
```python
count = 0
for i in range(1, 101):
    if i % 3 == 0:
        count += 1
print(count)   # 33
```

**Максимум от въведени числа:**
```python
n = int(input())
best = int(input())
for _ in range(n - 1):
    x = int(input())
    if x > best:
        best = x
print(best)
```

## break

`break` прекратява цикъла веднага:

```python
while True:
    password = input()
    if password == "bglearn":
        print("Добре дошли!")
        break
    print("Грешна парола, опитай пак.")
```

# Обобщение

- **for** — известен брой повторения; `range(start, stop, step)`, stop не се включва.
- **while** — докато условието е вярно; внимавай за безкраен цикъл.
- Сума: `total += x`; брояч: `count += 1`; максимум: сравнявай с текущия най-голям.
- `break` — изход от цикъла.

# Записки

## Цикли

**for:**
```python
for i in range(a, b):   # a, a+1, ..., b-1
    ...
```
**while:**
```python
while условие:
    ...   # промени условието!
```

**Шаблони:** сума (`total = 0`, `total += x`), брояч (`count += 1`), максимум (`if x > best: best = x`).

**break** — излиза от цикъла.

# Важно за запомняне

- `range(n)` започва от 0 и има n числа.
- Инициализирай сумата с 0 **преди** цикъла.

# Чести грешки

- `range(1, 10)`, когато трябва и 10 → `range(1, 11)`.
- `total = 0` **вътре** в цикъла — нулира се всеки път.
- `while` без промяна на променливата в условието → безкраен цикъл.

# Определения

- **Цикъл** — конструкция, която повтаря блок от команди.
- **Итерация** — едно изпълнение на тялото на цикъла.
- **Брояч** — променлива, която отчита колко пъти нещо се е случило.

# Въпроси от учителя

## Кога избираш for и кога while?

`for` — когато знам броя на повторенията (или обхождам поредица). `while` — когато повтарям, докато се изпълни условие, без да знам предварително колко пъти.

## Какви числа дава range(2, 11, 3)?

2, 5, 8 (11 не се достига).

# Упражнения

## Задача 1 (лесна)

Отпечатай четните числа от 2 до 20.

### Решение

```python
for i in range(2, 21, 2):
    print(i)
```

## Задача 2 (средна)

Въвеждат се числа, докато не се въведе 0. Отпечатай сумата им.

### Решение

```python
total = 0
x = int(input())
while x != 0:
    total += x
    x = int(input())
print(total)
```

## Колко пъти ще се изпълни тялото на `for i in range(10):`?

Число: 10

> i = 0, 1, …, 9.

## Какво ще отпечата програмата?

```python
s = 0
for i in range(1, 5):
    s += i
print(s)
```

Число: 10

> 1 + 2 + 3 + 4 = 10.

- [x] Когато условието на while никога не става невярно
- [ ] Когато използваме range
- [ ] Когато цикълът има break

> Нещо в тялото трябва да промени условието.
