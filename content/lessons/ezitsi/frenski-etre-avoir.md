# Въведение

**Être** (съм) и **avoir** (имам) са неправилни глаголи, но ги използваш във всяко второ изречение — и като самостоятелни глаголи, и като **спомагателни** за миналото време. Научи ги наизуст в първата седмица.

# Обяснение

## Спрежение в сегашно време

| | **être** — съм | **avoir** — имам |
|---|---|---|
| je / j' | **suis** | **ai** (j'ai) |
| tu | **es** | **as** |
| il / elle / on | **est** | **a** |
| nous | **sommes** | **avons** |
| vous | **êtes** | **avez** |
| ils / elles | **sont** | **ont** |

:::warning[Сливане]
Пред гласна *je* става **j'**: *j'ai*, но *je suis*. Внимавай за произношението: *ils sont* [сон] (съм) ≠ *ils ont* [зон] (имат) — при *ils ont* има свързване със звук „з“.
:::

## Употреба на être

- Самоличност, професия, националност: *Je suis élève.* *Elle est bulgare.*
- Описание: *Le livre est intéressant.*
- Местоположение: *Nous sommes à Sofia.*

## Употреба на avoir

- Притежание: *J'ai un chien.*
- **Възраст** — с avoir, не с être: *J'**ai** 15 ans.* (буквално „имам 15 години“)
- **Усещания**: *avoir faim* (гладен съм), *avoir soif* (жаден), *avoir froid / chaud* (студено / горещо ми е), *avoir peur* (страх ме е), *avoir raison* (прав съм).
- **Il y a** — има (съществува): *Il y a un parc près d'ici.*

## Спомагателни глаголи

В минало време (*passé composé*) повечето глаголи се спрягат с **avoir** (*j'ai mangé* — ядох), а глаголите за движение и възвратните — с **être** (*je suis allé* — отидох).

## Отрицание

*ne … pas* около глагола: *Je **ne** suis **pas** fatigué.* *Je **n'**ai **pas** de frère.* (след отрицание *un/une/des* → **de**)

# Примери

- *Tu **es** français ?* — Ти французин ли си?
- *Nous **avons** un examen demain.* — Утре имаме изпит.
- *Ils **sont** en classe.* — Те са в клас.
- *Elle **a** froid.* — Студено ѝ е.
- *J'**ai** seize ans.* — На 16 години съм.

# Обобщение

- être: suis, es, est, sommes, êtes, sont.
- avoir: ai, as, a, avons, avez, ont.
- Възраст и усещания — с **avoir**.
- И двата са спомагателни за passé composé.

# Записки

## être / avoir

| | être | avoir |
|---|---|---|
| je | suis | ai (j'ai) |
| tu | es | as |
| il/elle | est | a |
| nous | sommes | avons |
| vous | êtes | avez |
| ils/elles | sont | ont |

- **avoir + ... ans** — възраст.
- **avoir faim / soif / froid / chaud / peur.**
- **il y a** — има.
- **ne … pas** (+ de вместо un/une/des).

# Важно за запомняне

- „На 15 години съм“ = *J'ai 15 ans*, не ~~*Je suis 15 ans*~~.
- *ils sont* ≠ *ils ont*.

# Чести грешки

- ~~*Je suis faim.*~~ → *J'ai faim.*
- ~~*Je ai*~~ → *J'ai.*
- ~~*Je n'ai pas un frère.*~~ → *Je n'ai pas **de** frère.*

# Определения

- **Спрежение** — изменение на глагола по лице и число.
- **Спомагателен глагол** — глагол, с който се образуват сложни времена (*avoir*, *être*).

# Въпроси от учителя

## Как казваш на френски „На 14 години съм“?

*J'ai quatorze ans.* — с глагола avoir.

## Каква е разликата между *ils sont* и *ils ont*?

*Ils sont* — те са (être); *ils ont* — те имат (avoir). При *ils ont* се чува свързващо „з“.

# Упражнения

## Задача 1 (лесна)

Попълни с être: Nous ___ amis. Vous ___ prêts ?

### Решение

Nous **sommes** amis. Vous **êtes** prêts ?

## Задача 2 (средна)

Преведи: „Жаден съм. Сестра ми е на 10 години.“

### Решение

*J'ai soif. Ma sœur a dix ans.*

# Тест

## Nous ___ en France. (être)

- [ ] avons
- [x] sommes
- [ ] êtes

> nous sommes.

## Как се казва „Гладен съм“?

- [x] J'ai faim.
- [ ] Je suis faim.
- [ ] J'est faim.

> Усещанията — с avoir.

## Попълни: Ils \_\_\_ deux chats. (avoir)

Отговор: ont

> ils ont — те имат.

## Свържи местоимението с формата на être.

- je => suis
- tu => es
- vous => êtes
- ils => sont

## Кое изречение е правилно?

- [x] J'ai quinze ans.
- [ ] Je suis quinze ans.
- [ ] J'ai quinze années vieux.

> Възраст — с avoir + ans.
