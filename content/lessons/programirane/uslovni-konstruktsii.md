# Въведение

Без условия програмата прави винаги едно и също. С **условна конструкция** тя проверява нещо и според отговора избира какво да направи: „ако паролата е вярна — влез, иначе — покажи грешка“.

# Обяснение

## Булеви стойности и сравнения

Условието е израз, който е **вярно** (`True`) или **невярно** (`False`).

| Оператор | Значение | Пример | Резултат |
|---|---|---|---|
| `==` | равно ли е | `5 == 5` | `True` |
| `!=` | различно ли е | `5 != 3` | `True` |
| `<`, `>` | по-малко, по-голямо | `2 > 7` | `False` |
| `<=`, `>=` | по-малко или равно, по-голямо или равно | `6 >= 6` | `True` |

:::warning[= и ==]
`=` **присвоява** стойност (`x = 5`), а `==` **сравнява** (`x == 5`). Объркването им е най-честата грешка.
:::

## if, elif, else

```python
grade = 5.40

if grade >= 5.50:
    print("Отличен")
elif grade >= 4.50:
    print("Много добър")
elif grade >= 3.50:
    print("Добър")
else:
    print("Под добър")
```

- Проверките вървят **отгоре надолу**.
- Изпълнява се **само първият** клон, чието условие е вярно — останалите се пропускат.
- `else` се изпълнява, ако **нито едно** условие не е вярно.
- В Python блокът се определя с **отстъп** (4 интервала). В C#, Java и JavaScript се използват фигурни скоби `{ }`.

Горната програма отпечатва **„Много добър“**.

## Логически оператори

| Python | C# / Java / JS | Значение |
|---|---|---|
| `and` | `&&` | и двете условия са верни |
| `or` | `\|\|` | поне едното е вярно |
| `not` | `!` | обръща стойността |

```python
age = 16
has_permission = True

if age >= 18 or has_permission:
    print("Може да участва")
```

```python
x = 7
if x > 0 and x % 2 == 0:
    print("положително четно")
else:
    print("не е положително четно")
```

## Вложени условия

Можеш да сложиш `if` в друг `if`, но често е по-ясно да комбинираш условията с `and`.

# Примери

**Пример 1 — четно или нечетно:**

```python
n = int(input())
if n % 2 == 0:
    print("четно")
else:
    print("нечетно")
```

**Пример 2 — по-голямото от две числа:**

```python
a = int(input())
b = int(input())
if a > b:
    print(a)
else:
    print(b)
```

**Пример 3 — същото на C#:**

```csharp
int a = int.Parse(Console.ReadLine());
if (a > 0) { Console.WriteLine("положително"); }
else if (a < 0) { Console.WriteLine("отрицателно"); }
else { Console.WriteLine("нула"); }
```

# Обобщение

- Условието е `True` или `False`.
- `==` сравнява, `=` присвоява.
- `if` → `elif` → `else`: изпълнява се **първият** верен клон.
- `and`, `or`, `not` комбинират условия.

# Записки

## Условни конструкции

**Сравнения:** `==` `!=` `<` `>` `<=` `>=` → `True` / `False`.

**Синтаксис (Python):**
```python
if условие:
    ...
elif друго_условие:
    ...
else:
    ...
```
- проверява се отгоре надолу;
- изпълнява се само първият верен клон;
- `else` — ако нищо не е вярно.

**Логически:** `and` (&&), `or` (||), `not` (!).

# Важно за запомняне

- Само един клон се изпълнява.
- Отстъпът в Python е част от синтаксиса.
- Подреждай условията от най-тясното към най-широкото.

# Чести грешки

- `if x = 5:` вместо `if x == 5:`.
- Да подредиш условията грешно: ако първо проверяваш `grade >= 3.50`, оценка 6 ще отпечата „Добър“.
- Да забравиш двоеточието `:` или отстъпа в Python.

# Определения

- **Условна конструкция** — оператор, който изпълнява различен код според това дали условие е вярно.
- **Булев тип** — тип с две стойности: вярно (`True`) и невярно (`False`).
- **Логически оператор** — `and`, `or`, `not`; комбинира или обръща булеви стойности.

# Въпроси от учителя

## Какво ще стане, ако две условия в if/elif са верни едновременно?

Изпълнява се само първото от тях — останалите клонове се пропускат.

## Каква е разликата между and и or?

`and` е вярно само ако и двете условия са верни; `or` е вярно, ако поне едното е вярно.

# Упражнения

## Задача 1 (лесна)

Напиши програма, която чете число и отпечатва „положително“, „отрицателно“ или „нула“.

### Решение

```python
n = float(input())
if n > 0:
    print("положително")
elif n < 0:
    print("отрицателно")
else:
    print("нула")
```

## Задача 2 (средна)

Година е високосна, ако се дели на 4, но не на 100, или ако се дели на 400. Напиши условието.

### Подсказка

Използвай `%`, `and`, `or`.

### Решение

```python
year = int(input())
if (year % 4 == 0 and year % 100 != 0) or year % 400 == 0:
    print("високосна")
else:
    print("не е високосна")
```

## Задача 3 (средна)

Какво ще отпечата кодът при `t = 25`?

```python
if t > 30:
    print("горещо")
elif t > 20:
    print("топло")
elif t > 10:
    print("хладно")
else:
    print("студено")
```

### Решение

„топло“ — първото вярно условие е `t > 20`.

# Тест

## Какъв е резултатът от `7 >= 7`?

- [x] True
- [ ] False

> По-голямо **или равно** — 7 е равно на 7.

## Какво ще отпечата кодът при `x = 10`?

```python
if x > 5:
    print("A")
elif x > 8:
    print("B")
else:
    print("C")
```

- [x] A
- [ ] B
- [ ] A и B
- [ ] C

> Изпълнява се само първият верен клон.

## Кой оператор сравнява за равенство в Python?

- [ ] =
- [x] ==
- [ ] ===

> `=` присвоява; `===` има в JavaScript, но не и в Python.

## Кога `a and b` е True?

- [x] Когато и `a`, и `b` са True
- [ ] Когато поне едното е True
- [ ] Винаги

> За „поне едното“ е `or`.

## Колко е `17 % 5` (остатъкът при деление)?

Число: 2

> 17 = 3 · 5 + 2.
